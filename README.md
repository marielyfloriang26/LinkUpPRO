Objetivo general 

Desarrollar una aplicación web de red social que permita a los usuarios registrarse, 
activar su cuenta mediante correo electrónico, iniciar sesión de forma segura y 
gestionar la información de su perfil. 
La plataforma debe permitir crear, editar y eliminar publicaciones compuestas por 
texto acompañado de una imagen o un video de YouTube. Los usuarios podrán 
interactuar con las publicaciones mediante comentarios, respuestas anidadas y 
reacciones de “Me gusta” o “No me gusta”. 

El sistema también debe permitir enviar, aceptar, rechazar y eliminar solicitudes de 
amistad, administrar la lista de amigos y consultar las publicaciones realizadas por 
estos. 
Además, los usuarios podrán iniciar partidas de Battleship con sus amigos, 
posicionar sus barcos, realizar ataques por turnos, rendirse y consultar tanto las 
partidas activas como el historial de resultados. 
La aplicación debe garantizar que cada usuario solo pueda modificar el contenido 
creado por él, proteger el acceso a las funcionalidades internas y mantener la 
integridad de las relaciones, publicaciones y partidas registradas en el sistema.
